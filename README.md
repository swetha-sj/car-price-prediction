# Car Price Prediction

## Project Overview
This project focuses on predicting the selling price of cars using machine learning techniques based on various vehicle features.

## Objectives
- Analyze car-related data.
- Perform data preprocessing and exploratory data analysis.
- Build a machine learning model to predict car prices.
- Evaluate model performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project File
- `car_price_prediction.ipynb` – Contains the project code, data analysis, model building and predictions.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook using Jupyter Notebook or VS Code.
4. Run the cells sequentially.
